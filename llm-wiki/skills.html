这是什么

给 AI 编程助手用的 Sa-Token 开发 Skill。推荐 1.46.0+，核心 API 向后兼容。完全本地自包含，不依赖外部文档站点，离线可用。14 篇本地参考覆盖从集成配置到微服务网关鉴权的全链路，附带 28 条反模式纠偏、6 个关键决策检查点、12 条核心强约束和 9 项输出前自检清单。

适用场景

适用于：项目已使用 Sa-Token 依赖（sa-token-spring-boot-starter / sa-token-spring-boot3-starter / sa-token-spring-boot4-starter / sa-token-reactor-spring-boot-starter），涉及登录认证、权限校验（RBAC）、注解鉴权、路由拦截、Session、Redis 集成、前后端分离、踢人下线、账号封禁、SSO 单点登录、OAuth2.0、微服务网关鉴权、JWT / API-Key 等插件。

不适用于：Shiro / Spring Security 项目、纯 JWT 自实现方案、非 Java 语言。

部分适用：纯 Spring Security 项目——仅异常码参考章节可借用。
