Sa-Token 开发辅助 Skill — 混合渐进式封装

这是什么

一个面向 AI 编程助手的 Sa-Token 开发 Skill。采用混合渐进式设计：高频稳定的核心机制（登录认证、权限角色、注解鉴权、路由拦截、Session、Redis 集成等）做成 9 篇本地速查，AI 离线秒查；SSO、OAuth2、微服务网关、插件等低频易变模块则通过在线文档按需获取，内容永不腐化。所有内容基于稳定版 1.45.0，无编造。

目录结构

sa-token-dev/
├── SKILL.md # 决策路由 + 核心 API 速记 + 在线兜底指引
└── references/
    ├── 01-setup.md 集成配置（SpringBoot 依赖 / 框架适配）
    ├── 02-login-auth.md 登录认证 / Token 有效期
    ├── 03-permission.md 权限认证 / 角色鉴权
    ├── 04-annotation.md 注解鉴权 @SaCheck*
    ├── 05-interceptor-route.md 路由拦截 SaInterceptor / SaRouter
    ├── 06-session.md Session 会话 / 三大作用域
    ├── 07-redis-frontsep.md 集成 Redis / 前后端分离
    ├── 08-api-stputil.md StpUtil 常用 API 速查表
    └── 09-pitfalls.md 常见坑（未登录场景值 / 跨域 / 反代 / 异常码）

下载

获取 Sa-Token 开发 Skill 安装包：

curl -L https://baixuanzhu.github.io/Sa-Token/skills/sa-token-dev.zip -o sa-token-dev.zip

⬇ 下载 sa-token-dev.zip

解压后将 sa-token-dev/ 文件夹放入你所用 AI 编程助手的技能目录即可使用。
